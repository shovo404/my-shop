# 🛍️ My Premium Animated Shop

এটি একটি আধুনিক এবং ডাইনামিক ই-কমার্স প্রোডাক্ট শোকেস ওয়েবসাইট। এখানে গ্রাহকরা চমৎকার অ্যানিমেশনের মাধ্যমে প্রোডাক্ট দেখতে পারবেন এবং অ্যাডমিন প্যানেল থেকে রিয়েল-টাইমে পণ্যের দাম পরিবর্তন করা সম্ভব।

## ✨ ফিচারসমূহ:
- **Premium UI:** Tailwind CSS এবং Glassmorphism ডিজাইন।
- **Animations:** AOS.js ব্যবহার করে চমৎকার স্ক্রল অ্যানিমেশন।
- **Real-time Database:** Firebase Firestore ব্যবহার করে দাম আপডেট করা হয়।
- **Admin Panel:** সহজে প্রোডাক্ট যোগ এবং দাম পরিবর্তনের ব্যবস্থা।
- **Responsive:** মোবাইল এবং ডেক্সটপ সব ডিভাইসে ব্যবহারযোগ্য।

## 🛠️ টেকনোলজি:
- **Frontend:** HTML5, Tailwind CSS, JavaScript
- **Backend/DB:** Firebase Firestore
- **Hosting:** GitHub Pages
